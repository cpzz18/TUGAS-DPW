JAX & jQuery

AJAX

AJAX adalah teknik untuk mengirim dan menerima data dari server tanpa refresh halaman. Contoh: saat scroll Facebook, postingan baru muncul tanpa reload.

jQuery

jQuery adalah library JavaScript yang mempermudah penulisan kode JS. Dengan jQuery, kode menjadi lebih singkat dan mudah.

Masukkan library jQuery ke HTML via CDN

<src="https://code.jquery.com/jquery-4.0.0.js"
integrity="sha256-9fsHeVnKBvqh3FB2HYu7g2xseAZ5MlN6Kz/qnkASV8U="
crossorigin="anonymous""></script>

Atau bisa juga: download filenya lalu panggil lokal.
