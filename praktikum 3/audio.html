Kesimpulan:
Elemen audio pada HTML digunakan untuk memutar file suara secara langsung di halaman web. Atribut controls memungkinkan pengguna mengontrol pemutaran audio seperti play, pause, dan volume. Atribut autoplay dapat digunakan untuk memutar audio secara otomatis, namun pada browser modern harus disertai dengan muted agar dapat berjalan. Dengan adanya elemen audio, halaman web menjadi lebih interaktif dan menarik.
