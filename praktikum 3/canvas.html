Canvas Game Sederhana

Kesimpulan:
Elemen canvas pada HTML digunakan untuk menggambar objek dan membuat animasi secara dinamis menggunakan JavaScript. Dari hasil percobaan, canvas dapat digunakan untuk membuat game sederhana seperti objek yang bergerak dan interaksi klik. Dengan memanfaatkan canvas, halaman web menjadi lebih interaktif dan menarik bagi pengguna.
