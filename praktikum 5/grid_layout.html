Kesimpulan Skenario 1: Dengan menggunakan display: grid;, elemen dengan class .tempat_grid diubah menjadi sebuah grid. Properti grid-template-columns: auto auto auto; mendefinisikan bahwa grid tersebut memiliki 3 kolom dengan lebar otomatis (menyesuaikan dengan konten terlebar di setiap kolom). Item-item di dalam grid (1 sampai 9) akan secara otomatis tersusun dalam format 3 baris × 3 kolom, membentuk sebuah tabel atau matriks.

Kesimpulan Skenario 3: Properti grid-column-gap mengatur jarak horizontal antar kolom, sedangkan grid-row-gap mengatur jarak vertikal antar baris. Semakin besar nilai gap, semakin renggang tampilannya. Semakin kecil nilai gap, semakin rapat. Contoh: grid-column-gap: 100px; dan grid-row-gap: 50px; menghasilkan jarak horizontal 100px dan vertikal 50px.

Kesimpulan Skenario 4: Properti grid-gap adalah singkatan untuk mengatur jarak antar kolom dan baris sekaligus. Contoh: grid-gap: 50px; menghasilkan jarak horizontal dan vertikal sebesar 50px. Jika ingin mengatur jarak yang berbeda untuk kolom dan baris, gunakan properti grid-column-gap dan grid-row-gap secara terpisah.
