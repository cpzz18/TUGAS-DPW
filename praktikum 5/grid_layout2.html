Penggunaan grid-column-start dan grid-column-end berfungsi untuk mengatur posisi dan lebar elemen dalam grid. Dengan mengubah nilai dari 2 ke 4, elemen kedua dapat melebar dan menempati lebih dari satu kolom, yaitu dari kolom ke-2 hingga kolom ke-3. Hal ini menunjukkan bahwa CSS Grid memungkinkan pengaturan layout yang fleksibel, sehingga elemen dapat disesuaikan ukurannya sesuai kebutuhan.

Properti grid-template-columns digunakan untuk menentukan jumlah dan ukuran kolom dalam CSS Grid. Ketika menggunakan nilai auto, lebar kolom akan menyesuaikan isi secara otomatis. Jika jumlah kolom dikurangi (misalnya menjadi 2 kolom), maka elemen akan tersusun ke bawah lebih banyak baris. Sedangkan jika menggunakan ukuran tetap seperti pixel (px), maka lebar setiap kolom akan mengikuti nilai yang ditentukan, sehingga ada kolom yang terlihat sempit dan ada yang lebih lebar. Hal ini menunjukkan bahwa CSS Grid sangat fleksibel dalam mengatur ukuran dan tata letak kolom sesuai kebutuhan desain.

Kesimpulan Skenario 1 Part 2:
Properti grid-row digunakan untuk mengatur tinggi dan posisi elemen pada baris di dalam CSS Grid. Dengan nilai grid-row: 1 / 4, elemen akan membentang dari baris ke-1 sampai sebelum baris ke-4, sehingga elemen tersebut menempati beberapa baris sekaligus (3 baris). Jika nilai diubah, maka tinggi elemen juga ikut berubah sesuai jumlah baris yang dilewati. Hal ini menunjukkan bahwa CSS Grid memungkinkan pengaturan layout secara fleksibel baik secara horizontal (kolom) maupun vertikal (baris).
