Uji coba 2




-name sama: Hanya bisa memilih satu, karena dianggap sebagai satu kelompok. -name berbeda: Bisa memilih semua, karena dianggap sebagai kelompok yang berbeda. Radio button digunakan untuk pilihan tunggal, name yang sama mengelompokkan pilihan.

Uji coba 3




-name sama: Tetap bisa dipilih banyak, tetapi saat dikirim ke server, data akan terkirim sebagai array. -name berbeda: Setiap checkbox berdiri sendiri, bisa dipilih semua. Checkbox bersifat independen, name yang sama berguna untuk mengelompokkan data yang dikirim.

Uji coba 4




-type color: Menampilkan pemilih warna, memungkinkan pengguna memilih warna dengan mudah. -type date: Menampilkan kalender untuk memilih tanggal, memudahkan input tanggal yang valid. -type button: Membuat tombol yang dapat diklik untuk menjalankan fungsi JavaScript, berguna untuk interaksi tanpa submit form.

Uji coba 5



-type datetime-local: Menampilkan pemilih tanggal dan waktu, memudahkan input tanggal dan waktu yang valid. -type month: Menampilkan pemilih bulan dan tahun, berguna untuk input yang hanya membutuhkan bulan dan tahun. -type email: Memvalidasi input sebagai alamat email, membantu memastikan format email yang benar.

Uji coba 6




-type="image" berfungsi sebagai tombol submit bergambar. -type="file" membuka dialog pilih file. -type="hidden" tidak tampil, tetapi nilainya ikut terkirim. Berguna untuk mengirim data tanpa interaksi pengguna.

Uji coba 7



-type number: Menampilkan input untuk angka dengan opsi validasi seperti min dan max, memudahkan input angka yang valid. -type range: Menampilkan slider untuk memilih nilai dalam rentang tertentu, memberikan cara interaktif untuk memilih nilai.

Uji coba 8




-type url: Memvalidasi input sebagai URL, membantu memastikan format URL yang benar. -type search: Menampilkan input untuk pencarian, sering kali dengan fitur tambahan seperti tombol clear. -type tel: Memvalidasi input sebagai nomor telepon, pattern dapat digunakan untuk memastikan format tertentu.

Uji coba 9



-type time: Menampilkan pemilih waktu, memudahkan input waktu yang valid. -type week: Menampilkan pemilih minggu dan tahun, berguna untuk input yang hanya membutuhkan minggu dan tahun.
