Jika Anda mengklik tombol "Kirim", data formulir akan dikirim ke halaman bernama "action_page.php".

Tombol Reset mengembalikan semua input ke nilai awal (Budi dan Prawira). Tombol Kirim mengirim data ke action_page.php. Atribut target="_self" membuka hasil di tab yang sama, target="_blank" membuka di tab baru. Method GET menampilkan data di URL (contoh: ?i_depan=Budi&i_belakang=Prawira) sehingga bisa di-bookmark tetapi kurang aman. Method POST menyembunyikan data di body request, lebih aman untuk data sensitif tetapi tidak bisa di-bookmark.
